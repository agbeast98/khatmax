# Frontend

Use this doc for UI, workbench, and visible product surfaces.
For the full product UI brief, read `frontend/brief.md`.

## Focus Areas
- Core workbench layout.
- AI workspace panels.
- Inspector and browser surfaces.
- Branding and product identity in the UI.

## Product Brief
- Build a premium AI Workspace, not a VS Code theme.
- Use the canonical logo from `resources/khatmax/khatmax-logo.png`.
- Keep the interface dark-first, spacious, calm, and precise.
- Make AI actions visible, explainable, and controllable.
- Combine workspace, agent control, inspection, live browser, memory, and deployment into one coherent surface.

## Rules
- Keep UI language consistent.
- Do not mix presentation changes with unrelated backend work.
- When the surface is important to the product story, document the intent here.
