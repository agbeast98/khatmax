# Khatmax UI Brief

## Product
- Name: Khatmax
- Tagline: AI Workspace for Developers
- Product type: an AI Workspace, not a simple IDE theme.

## Design Goal
- Create a premium, modern, calm, and confident workspace.
- Make the product feel intentional, polished, and production-ready.
- The first reaction should be: "Wow."

- Junior developers
- Senior developers

- Startups
- Enterprise teams
- Non-developers who want to build software

## Core Philosophy
- AI must be transparent.
- Users must always know what AI is doing.
- Users must always know why AI is doing it.
- Users must always know what AI will do next.

## Logo Rule
- Use `resources/khatmax/khatmax-logo.png`.
- Do not redesign it.
- Keep original proportions.

## Layout
- Left sidebar: explorer, search, git, extensions, AI workspace, deploy, settings
- Editor area: tabs, split editors, code intelligence, AI suggestions, inline chat
- Right sidebar: planner agent, frontend agent, backend agent, database agent, testing agent, deploy agent, memory, timeline, inspector, reasoning
- Bottom panel: terminal, output, problems, logs, runtime, network, performance, database, tasks

## AI Workspace
- This is the heart of the product.
- Include chat, planner, reasoning, timeline, memory, context, multi-agent control, tasks, suggestions, and voice.

## AI Inspector
- Combine ideas from React DevTools, Chrome DevTools, VS Code debugger, performance tools, network inspection, state inspection, and AI analysis.
- Make inspection feel native to the workspace.

## Live Browser
- Built-in browser preview.
- Real-time rendering.
- Responsive mode.
- Console, DOM, network, performance, accessibility, and hot reload support.

## Timeline
- Show every AI action.
- Examples: read file, analyze, search, call tool, modify code, run tests, deploy.
- Animate state changes clearly.

## Multi Agent Dashboard
- Each agent needs avatar, status, progress, current task, confidence, reasoning, resource usage, and ETA.

## Memory
- Visualize recent decisions, dependencies, architecture, and long-term memory.
- Show the project memory graphically, not as raw noise.

## Monitoring
- Show CPU, RAM, GPU, requests, errors, latency, cost, API usage, LLM usage, and token usage.
- Prefer realtime graphs with clear hierarchy.

## Style
- Dark mode first.
- Subtle glassmorphism.
- Soft shadows.
- Rounded corners.
- Large spacing.
- Premium typography.
- Minimal clutter.
- Smooth micro-animations.
- Elegant empty/loading states.
