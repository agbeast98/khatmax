# Roadmap

Use this doc for product direction and sequencing.

## Format
- `Now` — the active work.
- `Next` — the immediate follow-up.
- `Later` — items that matter but are not active yet.

## Now
- Khatmax AI Agent extension: scaffold, ChatProvider, OpenRouter gateway, streaming.
- Remove GitHub Copilot dependency from product.json.
- API key management with SecretStorage.

## Next
- Tool execution: file edit, terminal, search.
- Model selector UI with multi-model support.
- Transparent AI: progress events, thinking blocks, stop action.
- Error recovery, retry, rate limit handling.

## Later
- Khatmax API gateway (replace OpenRouter with own backend).
- Agent host process for advanced orchestration.
- Inline code completions (code suggestions while typing).
- Multi-agent collaboration and coordination.
- Memory graph and long-term context.
- Live Browser integration with AI inspection.

## Rules
- Keep the roadmap about product outcomes, not task noise.
- Update it when priorities or dependencies change.
- Keep it aligned with the current context and memory docs.
- Core engine stability before advanced features.
- UI identity before feature expansion.
