# 06 - Agent System

Agent System در Khatmax قلب اجرای هوشمند پروژه است. این بخش مسئول برنامه‌ریزی، اجرا، بازبینی، توقف، اصلاح و هماهنگی بین چند agent خواهد بود. اگر workspace مغز محصول باشد، agent system موتور اجرایی آن است.

## هدف
- انجام کارهای واقعی توسط AI
- تقسیم کار بین agentها
- نمایش شفاف تصمیم‌ها
- اجازه دادن به کاربر برای کنترل رفتار AI

## نقش‌های اصلی
- `Planner`: هدف را به مراحل قابل‌اجرا تبدیل می‌کند.
- `Executor`: کار عملی را انجام می‌دهد.
- `Inspector`: نتیجه را بررسی می‌کند و ریسک‌ها را می‌سنجد.
- `Coordinator`: بین agentها هماهنگی ایجاد می‌کند.
- `Memory Keeper`: context و history را نگه می‌دارد.

## اصول کنترل
- AI نباید پنهانی عمل کند.
- هر action باید وضعیت داشته باشد.
- کاربر باید بتواند دستورات را تایید، رد، متوقف یا ویرایش کند.
- در کارهای حساس، approval لازم باشد.

## رفتار شفاف
- agent باید بگوید چه می‌خواهد انجام دهد.
- agent باید بگوید چرا این تصمیم را گرفته است.
- agent باید نتیجه‌ی موقت و نهایی را جدا کند.
- agent باید خطاها و ابهام‌ها را گزارش دهد.

## ساختار اجرایی
- task به چند step شکسته می‌شود.
- stepها می‌توانند توسط agentهای مختلف اجرا شوند.
- timeline باید ترتیب تصمیم‌ها را نشان دهد.
- replay باید اجازه دهد مسیر اجرا دوباره دیده شود.

## memory و context
- context باید به task مربوط باشد.
- memory نباید بی‌قاعده بزرگ شود.
- داده‌ی غیرمرتبط نباید وارد تصمیم‌گیری شود.
- history باید برای بازبینی و ادامه‌ی کار قابل‌استفاده باشد.

## multi-agent behavior
- هر agent باید نقش مشخص داشته باشد.
- تداخل نقش‌ها باید حداقل باشد.
- coordination باید روشن و قابل‌ردگیری باشد.
- اگر دو agent به نتیجه‌ی متفاوت رسیدند، سیستم باید این اختلاف را مدیریت کند.

## safety
- دسترسی‌ها باید محدود باشند.
- کارهای حساس باید با تایید کاربر انجام شوند.
- agent نباید بدون مشاهده‌ی context کافی تصمیم نهایی بگیرد.
- تغییرات مخرب باید قبل از اجرا قابل‌تشخیص باشند.

## integration با workspace
- agent باید در workspace دیده شود، نه جدا از آن.
- status، reason, plan و output باید در UI قابل‌نمایش باشند.
- user باید بتواند مسیر agent را در خود IDE دنبال کند.

## نتیجه‌ی مطلوب
- کاربر بداند AI چه می‌کند.
- کاربر بتواند AI را هدایت کند.
- agentها بتوانند هماهنگ، شفاف و قابل‌اعتماد کار کنند.
- سیستم برای automation پیشرفته آماده باشد، بدون اینکه کنترل انسانی را حذف کند.
