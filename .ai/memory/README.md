# Memory

This folder holds the shortest useful context for continuing work.
It is not a log of everything.
It is the minimum state needed to resume a thread without rereading the whole repo.

## What To Keep
- Current goal.
- Last stable decision.
- Open questions.
- Next action.
- Active constraints.

## How To Use
- Update memory when a decision is durable.
- Remove stale items instead of piling up history.
- Keep the file compact enough that an agent can read it quickly.
