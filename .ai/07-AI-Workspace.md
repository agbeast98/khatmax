# 07 - AI Workspace

AI Workspace هسته‌ی تجربه‌ی Khatmax است. اینجا جایی است که کاربر پروژه را می‌بیند، با AI تعامل می‌کند، کارها را مدیریت می‌کند و وضعیت واقعی سیستم را دنبال می‌کند. این بخش نباید فقط یک chat panel باشد؛ باید مرکز کنترل پروژه باشد.

## هدف
- ایجاد یک محیط مرکزی برای ساخت پروژه با AI
- جمع‌کردن editor، agent، runtime و inspector در یک فضای واحد
- کمک به کاربر برای فهمیدن وضعیت واقعی پروژه
- امکان مدیریت ساده برای کاربر تازه‌کار و کنترل عمیق برای کاربر حرفه‌ای

## ویژگی‌های اصلی
- project overview
- task panel
- agent timeline
- reasoning view
- live status
- runtime controls
- browser preview
- memory/context view
- action approvals

## رفتار workspace
- workspace باید همیشه وضعیت فعلی پروژه را نشان دهد.
- کاربر باید بداند AI الان مشغول چیست.
- خروجی‌ها باید به task و context وصل باشند.
- هیچ action مهمی نباید خارج از دید workspace رخ دهد.

## ساختار محتوایی
- فایل‌ها و ساختار پروژه
- اهداف فعلی
- agentهای درگیر
- history و replay
- preview و runtime
- errors و warnings

## تجربه برای کاربر مبتدی
- کارهای پیچیده باید ساده‌سازی شوند.
- UI نباید کاربر را با اطلاعات زیاد غرق کند.
- پیشنهادها باید واضح و مرحله‌ای باشند.
- کاربر باید بتواند بدون دانش عمیق هم نتیجه بگیرد.

## تجربه برای کاربر حرفه‌ای
- باید کنترل دقیق روی agentها وجود داشته باشد.
- باید state، context و logها قابل بررسی باشند.
- باید امکان مداخله، اصلاح و automation بیشتر فراهم باشد.

## تعامل با AI
- AI باید پروژه را بشناسد.
- AI باید context workspace را بفهمد.
- AI باید بتواند proposal بدهد، اجرا کند و نتیجه را گزارش کند.
- AI نباید فقط پاسخ دهد؛ باید عمل کند.

## ساختار پیشنهادی UI
- سمت چپ: ساختار پروژه و navigation
- وسط: editor / task / runtime
- سمت راست: agent, reasoning, inspector
- پایین: log, terminal, status, events

## نتیجه‌ی مورد انتظار
- یک workspace واحد و هوشمند
- ترکیب کنترل، شفافیت و سرعت
- مناسب برای توسعه‌دهنده و غیرتوسعه‌دهنده
- آماده برای رشد به یک محصول مستقل
