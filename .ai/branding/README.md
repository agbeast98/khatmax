# Branding

The canonical Khatmax logo asset is `resources/khatmax/khatmax-logo.png`.
Use it as-is. Do not redesign or distort it.

## Rules
- Keep original proportions.
- Use the same logo asset across UI, docs, and product surfaces.
- Prefer the canonical asset path instead of copies scattered around the repo.
- If a surface needs a versioned variant, document why before creating one.
